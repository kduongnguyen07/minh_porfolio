# Nguyễn Quang Minh — Star Rail & TFT AI Portfolio

Một trang Web Portfolio cá nhân cao cấp dạng Single Page Application (SPA) của học viên **Nguyễn Quang Minh** (K70 AI Engineer - UET VNU, MSSV: `25020271`), được thiết kế dựa trên cảm hứng giao diện tương tác từ hai tựa game **Honkai: Star Rail (HSR)** và **Teamfight Tactics (TFT)**.

## 🌌 Các Tính Năng & Trải Nghiệm Lõi

1. **Hiệu ứng Không gian Lượng tử (Particle Space Background)**:
   - Nền động hạt không gian tương tác chạy mượt mà, phản hồi theo tọa độ chuột di chuyển.
2. **Cửa hàng Nhiệm vụ Gacha (HSR Gacha Warp Shop)**:
   - Hệ thống hiển thị các báo cáo thực hành dưới dạng cửa hàng thẻ bài HSR. Hỗ trợ tính năng Reroll (D) làm mới ngẫu nhiên các tác vụ bài tập.
3. **Mô phỏng Terminal & Cây thư mục (Nhiệm vụ 1)**:
   - Trình duyệt Terminal tương tác giả lập các lệnh git/ssh và hiển thị trực quan sơ đồ cây thư mục báo cáo.
4. **Trình mô phỏng Tìm kiếm thông tin (Nhiệm vụ 2)**:
   - Giả lập công cụ tìm kiếm học thuật thời gian thực với bộ lọc từ khóa nâng cao.
5. **Prompt Playground & Kanban Flow (Nhiệm vụ 3 & 4)**:
   - Trực quan hóa sân chơi so sánh kỹ thuật tối ưu hóa Prompt (Chain-of-Thought) và bảng quản trị Git Flow Kanban.
6. **Đạo đức AI & Lộ trình thu hoạch (Nhiệm vụ 6 & 8)**:
   - Phân tích chi tiết các quy tắc ứng dụng AI có trách nhiệm và biểu đồ phát triển lộ trình cá nhân.

## 🛠️ Công Nghệ Sử Dụng

- **Framework**: React.js (Vite)
- **Icons**: Lucide React
- **Styling**: Modern Cyberpunk CSS & Audio Synthesizer (Web Audio API tạo âm thanh bip/chime chuẩn game HSR)

## 🚀 Hướng Dẫn Chạy Dự Ản

### Cài đặt dependencies:
```bash
npm install
```

### Chạy ở chế độ phát triển (Development):
```bash
npm run dev
```

### Build cho môi trường production:
```bash
npm run build
```
